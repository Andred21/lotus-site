## Notas por item

- **`lang` `es` → `es-CL`**: o site publica `es` e o critério de aceite da EAP `3.1.1` pede `es-CL`. O critério é requisito escrito e o site é referência visual e de conteúdo, não autoridade arquitetural (`CLAUDE.md`). Divergência intencional sem efeito visual, na matriz de `README.md`.
- **1 só `h1`** — bom sinal de SEO. A contagem acima já está deduplicada: `dom.json` registra o mesmo `<h1>` uma vez por wrapper aninhado (`page-container`, `et-main-area`, `main-content`, `post-47805`, `Intrucción` apontam para o mesmo elemento no DOM), não 5 títulos diferentes.
- **Pulo de `h1` para `h3`**: o subtítulo do hero (`SERVICIOS DE CAPACITACIÓN Y CERTIFICACIÓN`) é `h3`, sem `h2` entre ele e o `h1` — hierarquia tecnicamente quebrada. Marcado `pendente decisão` porque corrigir é uma escolha de estrutura de conteúdo, não só trocar a tag.
- **`wp-sitemap-users-1.xml`** expõe `https://lotusotec.cl/author/admin/` — enumeração de usuário do WordPress. Não tem equivalente no clone (não existem usuários/autores no site estático); a linha de `sitemap` acima já cobre isso — o sitemap novo simplesmente não inclui esse tipo de URL.
- **`robots.txt` atual** só faz sentido para WordPress (`Disallow: /wp-admin/`) — o clone precisa de um `robots.txt` próprio, não uma cópia deste.
- Geradores expostos no `<head>` hoje: `Divi v.4.17.4`, `WordPress 7.1`, `Elementor 3.30.3` (`meta[name="generator"]`, 3 tags) — não têm equivalente no clone (não há gerador de CMS a anunciar); fica implícito no `criar`/`preservar` de cada item acima, sem linha própria porque não é um dado a decidir, é um artefato que simplesmente deixa de existir.
