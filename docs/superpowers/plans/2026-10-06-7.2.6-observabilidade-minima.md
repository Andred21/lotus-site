## Change sets — o que vale para as Tasks 3 e 4

Cada mudança na AWS segue o padrão de `B4` e `B5` (spec §6 e D14):

1. template e catraca verdes e commitados — nas Tasks 1 e 2; na Task 4, só se a sintaxe de uma consulta mudar, e aí **sem commit** até a medição;
2. change set criado e lido pelo agente: tabela de recursos e diff (abaixo);
3. **portão no estado** — commit só do `state.md`, com `workflow_state: blocked`, `resume_state: executing`, `next_owner: joao`, o `next_action` do passo e um `blocker` com o ARN do change set, a tabela, o diff e os arquivos editados e não commitados — a evidência em andamento inclusive —, se houver; antes do commit, `pnpm format && pnpm agent:check` e o grep do endereço; mensagem `chore(7.2.6): bloquear no portão …`;
4. execução por João, ou por Claude com autorização explícita dada naquele passo;
5. leitura e secção na evidência;
6. `state.md` de volta a `workflow_state: executing`, `next_owner: claude`, `next_action: continue_active_plan`, `resume_state: null`, `blocker: null` — na retomada, que o `/executar-site` faz, e sem commit próprio: a volta entra no commit da task, ou no portão seguinte quando a task tem mais de um.

Qualquer recurso fora do esperado, `Replacement` verdadeiro ou linha de diff fora da esperada **para o fluxo** em `blocked`, com o change set no `blocker`, sem executar.

Execute que falha também para o fluxo em `blocked`, com `next_action: decidir_falha_do_change_set` e, no `blocker`, o primeiro evento `*_FAILED` — lido só assim: o evento inteiro traz `ResourceProperties`, e o da `Assinatura` traz o endereço.

```bash
export AWS_PROFILE=lotus TZ=UTC
aws cloudformation describe-stack-events --region us-east-1 --stack-name lotus-observabilidade \
  --query "StackEvents[?ends_with(ResourceStatus, '_FAILED')] | [-1].{Recurso:LogicalResourceId,Estado:ResourceStatus,Quando:Timestamp,Motivo:ResourceStatusReason}" \
  --output json
```

A decisão é de João. `AccessDenied` sem causa em IAM tem a SCP da organização como primeira hipótese (spec §11): o perfil `lotus` tem `AdministratorAccess`, e a criação escreve pela primeira vez nesta conta em `logs:PutDeliverySource`, `cloudfront:AllowVendedLogDeliveryForResource`, `logs:PutDeliveryDestination`, `logs:CreateDelivery`, `logs:PutResourcePolicy`, `route53:CreateHealthCheck` e `sns:CreateTopic`.

- **Na criação**, o stack fica em `ROLLBACK_COMPLETE` e não aceita outro change set: só sai por `delete-stack`, que é de João. A correção do template, se houver, vira commit próprio (`fix(7.2.6): …`), com a catraca, antes do change set novo.
- **Numa atualização**, o stack volta sozinho ao que era (`UPDATE_ROLLBACK_COMPLETE`).

### Stack `lotus-observabilidade` (`us-east-1`)

Todo change set passa `--capabilities CAPABILITY_NAMED_IAM`, porque a role tem nome, e `--tags Projeto=lotus-site`, como o `lotus-dns`: o `deploy` manda a lista de tags em toda chamada, e uma atualização sem `--tags` pode tirar as do stack. `EmailDeAlerta` só vai na criação.

Criação (Task 3):

```bash
export AWS_PROFILE=lotus TZ=UTC
EMAIL=$(aws cloudformation describe-stacks --region sa-east-1 --stack-name lotus-site \
  --query "Stacks[0].Parameters[?ParameterKey=='EmailDeAlerta'].ParameterValue" --output text)
case "$EMAIL" in jv*@gmail.com) echo "destinatário: jv***@gmail.com" ;; *) echo "PARAR: destinatário fora de D2"; exit 1 ;; esac
aws cloudformation validate-template --region us-east-1 \
  --template-body file://infra/lotus-observabilidade.yaml --query Capabilities --output text
SAIDA=$(aws cloudformation deploy --region us-east-1 --stack-name lotus-observabilidade \
  --template-file infra/lotus-observabilidade.yaml --parameter-overrides EmailDeAlerta="$EMAIL" \
  --capabilities CAPABILITY_NAMED_IAM --tags Projeto=lotus-site --no-execute-changeset) || exit 1
CS=$(grep -oE 'arn:aws:cloudformation:[^ ]+:changeSet/[^ ]+' <<<"$SAIDA" | head -1); echo "change set: $CS"
aws cloudformation describe-change-set --region us-east-1 --change-set-name "$CS" \
  --query 'Changes[].ResourceChange.{Acao:Action,Recurso:LogicalResourceId,Tipo:ResourceType}' --output table
```

Expected da criação: `destinatário: jv***@gmail.com`, `CAPABILITY_NAMED_IAM`, `change set: arn:aws:cloudformation:us-east-1:760144413534:changeSet/…` e uma tabela de exatamente catorze linhas, todas `Add`: `Topico`, `Assinatura`, `SaudeDoSite`, `AlarmeDeSaude`, `Alarme5xx`, `Acessos`, `OrigemDoLog`, `DestinoDoLog`, `EntregaDoLog`, `Consulta5xx`, `ConsultaLatencia`, `ConsultaCache`, `ConsultaReleases` e `PapelDeAlerta`. Na criação não há diff por propriedade: tudo é novo, e o `AfterContext` da `Assinatura` traz o endereço.

Criar `scripts/infra/lib/yaml.mjs`:

```js
// Leitor do subconjunto de YAML que os templates de `infra/` e o `ci.yml`
// usam, sem parser de terceiro (Lei 7: `yaml` e `js-yaml` não resolvem na
// árvore, medido em 2026-09-20 por `zona.mjs`). Os leitores de `zona.mjs`,
// `cabecalhos.mjs` e `distribuicao.mjs` recortam um recurso cada um, por
// coluna; o stack de observabilidade (`B6`) tem catorze recursos de formas
// diferentes, e o `ci.yml` tem blocos de shell, então aqui a leitura é
// genérica e devolve a árvore inteira.
//
// O subconjunto: mapa e lista em bloco; escalar simples, entre aspas simples
// ou duplas; lista em fluxo de uma linha (`[a, b]`); tag curta guardada como
// texto cru (`!Ref Topico`, `!Sub '...'`); bloco literal ou dobrado (`|`,
// `|-`, `>`, `>-`). Escalar não é convertido: `true`, `30` e `0.5` chegam
// como texto, como nas outras catracas. O que fugir disso — âncora, mapa em
// fluxo, comentário no fim da linha, tabulação, chave repetida, recuo fora do
// lugar — lança erro com o número da linha: a leitura é assumida frágil e
// quebra ruidosamente, nunca vira valor lido pela metade. A validação
// estrutural continua com `aws cloudformation validate-template`.

// `Lista` existe só para o TypeScript aceitar a recursão no JSDoc.
/**
 * @typedef {string | Lista | Mapa} Valor
 * @typedef {Valor[]} Lista
 * @typedef {{ [chave: string]: Valor }} Mapa
 * @typedef {{ item: boolean, recuo: number, texto: string, numero: number, bloco?: string }} Token
 */

// Chave sem espaço, que não começa por indicador de YAML; o `?` deixa passar
// `:` no meio, como em `token.actions.githubusercontent.com:aud`.
const CHAVE = /^([^\s'"!&*[\]{}#|>%@`-]\S*?):(?:\s+(.*))?$/
const CABECALHO_DE_BLOCO = /^[|>]-?$/

/**
 * @param {string} bruto
 * @param {number} numero
 * @returns {Valor}
 */
function escalar(bruto, numero) {
  const valor = bruto.trim()
  if (valor.startsWith("'")) {
    if (!/^'(?:[^']|'')*'$/.test(valor)) {
      throw new Error(`linha ${numero}: aspas simples sem fechar: ${valor}`)
    }
    return valor.slice(1, -1).replaceAll("''", "'")
  }
  if (valor.startsWith('"')) {
    if (!/^"(?:[^"\\]|\\.)*"$/.test(valor)) {
      throw new Error(`linha ${numero}: aspas duplas sem fechar: ${valor}`)
    }
    return valor.slice(1, -1).replace(/\\(.)/g, (_todo, letra) => {
      const troca = { n: '\n', t: '\t', '"': '"', '\\': '\\' }[String(letra)]
      if (troca === undefined) {
        throw new Error(`linha ${numero}: escape não lido: \\${letra}`)
      }
      return troca
    })
  }
  if (valor.startsWith('[')) {
    const dentro = valor.match(/^\[(.*)\]$/)?.[1]
    if (dentro === undefined || /[[\]{}]/.test(dentro)) {
      throw new Error(`linha ${numero}: lista em fluxo não lida: ${valor}`)
    }
    return dentro.trim() === ''
      ? []
      : dentro.split(',').map((parte) => escalar(parte, numero))
  }
  if (/^[{&*]/.test(valor)) {
    throw new Error(`linha ${numero}: mapa em fluxo, âncora ou alias: ${valor}`)
  }
  if (/\s#/.test(valor)) {
    throw new Error(`linha ${numero}: comentário no fim da linha: ${valor}`)
  }
  return valor
}

/**
 * Bloco dobrado (`>`): linha seguida de linha vira espaço; linha em branco
 * vira quebra.
 * @param {string[]} corpo
 */
function dobrar(corpo) {
  let texto = ''
  corpo.forEach((linha, k) => {
    if (k === 0) texto = linha
    else if (linha === '') texto += '\n'
    else texto += corpo[k - 1] === '' ? linha : ` ${linha}`
  })
  return texto
}

/**
 * Uma linha de conteúdo vira um token; `- ` vira um token de item e o resto
 * da linha segue, duas colunas à direita. Bloco literal é lido aqui, porque o
 * conteúdo dele não obedece às regras de comentário e recuo.
 * @param {string} texto
 * @returns {Token[]}
 */
function tokenizar(texto) {
  const linhas = texto.split('\n')
  /** @type {Token[]} */
  const tokens = []
  for (let i = 0; i < linhas.length; i++) {
    const linha = linhas[i] ?? ''
    if (/^\s*(#.*)?$/.test(linha)) continue
    if (/^ *\t/.test(linha)) {
      throw new Error(`linha ${i + 1}: tabulação na indentação`)
    }
    let recuo = linha.length - linha.trimStart().length
    let resto = linha.trim()
    let traco = -1
    while (resto === '-' || resto.startsWith('- ')) {
      tokens.push({ item: true, recuo, texto: '-', numero: i + 1 })
      traco = recuo
      const depois = resto.slice(1)
      recuo += 1 + depois.length - depois.trimStart().length
      resto = depois.trimStart()
    }
    if (resto === '') continue
    /** @type {Token} */
    const token = { item: false, recuo, texto: resto, numero: i + 1 }
    tokens.push(token)
    const chave = resto.match(CHAVE)
    const cabecalho = chave ? (chave[2] ?? '') : resto
    if (!/^[|>]/.test(cabecalho)) continue
    if (!CABECALHO_DE_BLOCO.test(cabecalho)) {
      throw new Error(
        `linha ${i + 1}: cabeçalho de bloco não lido: ${cabecalho}`,
      )
    }
    // O conteúdo fica à direita da chave dona; item de lista sem chave
    // (`- |`) mede pela coluna do traço.
    const limite = chave ? recuo : traco
    /** @type {string[]} */
    const corpo = []
    let base = -1
    while (i + 1 < linhas.length) {
      const proxima = linhas[i + 1] ?? ''
      if (proxima.trim() !== '') {
        const r = proxima.length - proxima.trimStart().length
        if (r <= limite) break
        if (base === -1) base = r
        if (r < base) {
          throw new Error(
            `linha ${i + 2}: bloco com recuo menor que o da primeira linha`,
          )
        }
      }
      corpo.push(proxima.trim() === '' ? '' : proxima.slice(base))
      i++
    }
    while (corpo.at(-1) === '') corpo.pop()
    const conteudo = cabecalho.startsWith('>')
      ? dobrar(corpo)
      : corpo.join('\n')
    token.bloco = cabecalho.endsWith('-') ? conteudo : `${conteudo}\n`
  }
  return tokens
}

/**
 * Lê o documento inteiro. A raiz precisa ser um mapa.
 * @param {string} texto
 * @returns {Mapa}
 */
export function lerYaml(texto) {
  const tokens = tokenizar(texto)
  let k = 0

  /**
   * @param {number} recuo
   * @returns {Valor}
   */
  const lerNo = (recuo) => {
    const token = tokens[k]
    if (!token) return ''
    if (token.item) return lerLista(recuo)
    if (CHAVE.test(token.texto)) return lerMapa(recuo)
    k++
    return token.bloco ?? escalar(token.texto, token.numero)
  }

  /**
   * @param {number} recuo
   * @returns {Valor[]}
   */
  const lerLista = (recuo) => {
    /** @type {Valor[]} */
    const lista = []
    for (
      let token = tokens[k];
      token?.item && token.recuo === recuo;
      token = tokens[k]
    ) {
      k++
      const proximo = tokens[k]
      lista.push(proximo && proximo.recuo > recuo ? lerNo(proximo.recuo) : '')
    }
    return lista
  }

  /**
   * @param {number} recuo
   * @returns {Mapa}
   */
  const lerMapa = (recuo) => {
    /** @type {Mapa} */
    const lido = {}
    for (
      let token = tokens[k];
      token && !token.item && token.recuo === recuo;
      token = tokens[k]
    ) {
      const partes = token.texto.match(CHAVE)
      if (!partes) {
        throw new Error(`linha ${token.numero}: esperava chave: ${token.texto}`)
      }
      const chave = partes[1] ?? ''
      if (Object.hasOwn(lido, chave)) {
        throw new Error(`linha ${token.numero}: chave repetida: ${chave}`)
      }
      k++
      const resto = partes[2] ?? ''
      const proximo = tokens[k]
      if (resto === '') {
        lido[chave] =
          proximo && proximo.recuo > recuo ? lerNo(proximo.recuo) : ''
        continue
      }
      // Tag sozinha com bloco embaixo (`Value: !Join` e a lista na linha
      // seguinte) vira `{ '!Join': [...] }`.
      if (/^!\w+$/.test(resto) && proximo && proximo.recuo > recuo) {
        lido[chave] = { [resto]: lerNo(proximo.recuo) }
        continue
      }
      lido[chave] = token.bloco ?? escalar(resto, token.numero)
      if (proximo && proximo.recuo > recuo) {
        throw new Error(
          `linha ${proximo.numero}: recuo inesperado depois de ${chave}`,
        )
      }
    }
    return lido
  }

  const raiz = lerNo(0)
  const sobra = tokens[k]
  if (sobra) {
    throw new Error(`linha ${sobra.numero}: fora da estrutura: ${sobra.texto}`)
  }
  if (typeof raiz !== 'object' || Array.isArray(raiz)) {
    throw new Error('o documento não é um mapa')
  }
  return raiz
}

/**
 * O próprio valor, se for mapa; senão, erro com o caminho de onde veio.
 * @param {Valor | undefined} valor
 * @param {string} caminho
 * @returns {Mapa}
 */
export function mapa(valor, caminho) {
  if (typeof valor !== 'object' || Array.isArray(valor)) {
    throw new Error(`${caminho}: esperava um mapa`)
  }
  return valor
}
```

```js
  IdDoHealthCheck: '!Ref SaudeDoSite',

/** @param {Valor | undefined} valor */
function descrever(valor) {
  if (valor === undefined) return 'ausente'
  return typeof valor === 'string' ? valor : JSON.stringify(valor)
}

/**
 * Compara `veio` com o subconjunto `esperado`, folha a folha. Lista compara o
 * tamanho e cada item; mapa compara só as chaves de `esperado`.
 * @param {string} caminho
 * @param {Valor} esperado
 * @param {Valor | undefined} veio
 * @param {string[]} problemas
 */
export function conferirCampos(caminho, esperado, veio, problemas) {
  if (typeof esperado === 'string') {
    if (veio !== esperado) {
      problemas.push(
        `${caminho}: esperado ${esperado}, veio ${descrever(veio)}`,
      )
    }
    return
  }
  if (Array.isArray(esperado)) {
    if (!Array.isArray(veio) || veio.length !== esperado.length) {
      problemas.push(
        `${caminho}: esperado ${JSON.stringify(esperado)}, veio ${descrever(veio)}`,
      )
      return
    }
    esperado.forEach((item, i) =>
      conferirCampos(`${caminho}[${i}]`, item, veio[i], problemas),
    )
    return
  }
  if (typeof veio !== 'object' || Array.isArray(veio)) {
    problemas.push(`${caminho}: esperado um mapa, veio ${descrever(veio)}`)
    return
  }
  for (const [chave, valor] of Object.entries(esperado)) {
    conferirCampos(`${caminho}.${chave}`, valor, veio[chave], problemas)
  }
}

/**
 * `Action` e `Resource` de IAM aceitam texto ou lista.
 * @param {Valor | undefined} valor
 * @returns {Valor[]}
 */
function emLista(valor) {
  if (valor === undefined) return []
  return Array.isArray(valor) ? valor : [valor]
}

/**
 * `Properties` do recurso, ou `{}` quando ele falta: a falta já sai como
 * problema na comparação com `RECURSOS_ESPERADOS`.
 * @param {Mapa} recursos
 * @param {string} nome
 * @returns {Mapa}
 */
function propriedades(recursos, nome) {
  const recurso = recursos[nome]
  if (typeof recurso !== 'object' || Array.isArray(recurso)) return {}
  const dentro = recurso.Properties
  return typeof dentro === 'object' && !Array.isArray(dentro) ? dentro : {}
}

/**
 * Defaults medidos e o e-mail fora do repositório (D2, D6, D7).

    problemas.push(

}

/**
 * O que a comparação por subconjunto não pega: tópico sem SSE (D11), regiões
 * do health check (D7), nome do log group e campos do log (D8).
 * @param {Mapa} recursos
 * @param {string[]} problemas
 */
function conferirRestricoes(recursos, problemas) {
  if (propriedades(recursos, 'Topico').KmsMasterKeyId !== undefined) {
    problemas.push(
      'Topico.Properties.KmsMasterKeyId: com SSE o CloudWatch não publica (D11)',

  if (campos === undefined) {

/**

 * do template, inclusive uma quinta que alguém acrescente.
 * @param {Mapa} recursos

/**
 * A role de alerta: só `sns:Publish`, só no tópico, e a trust igual à da role
 * de deploy do `lotus-site`, com os mesmos `Default` de repositório (D10).
 * @param {Mapa} template
 * @param {Mapa} site
 * @param {string[]} problemas
 */
function conferirPapelDeAlerta(template, site, problemas) {
  const papel = propriedades(
    mapa(template.Resources, 'Resources'),
    'PapelDeAlerta',
  )
  for (const proibida of ['ManagedPolicyArns', 'PermissionsBoundary']) {
    if (papel[proibida] !== undefined) {
      problemas.push(
        `PapelDeAlerta.Properties.${proibida}: a role só publica no tópico (D10)`,
      )
    }
  }
  const politicas = emLista(papel.Policies)
  if (politicas.length === 0) {
    problemas.push('PapelDeAlerta.Properties.Policies: ausente')
  }
  politicas.forEach((politica, i) => {
    const onde = `PapelDeAlerta.Policies[${i}]`
    const documento = mapa(mapa(politica, onde).PolicyDocument, onde)
    emLista(documento.Statement).forEach((bruta, j) => {
      const declaracao = mapa(bruta, `${onde}.Statement[${j}]`)
      for (const aberta of ['NotAction', 'NotResource']) {
        if (declaracao[aberta] !== undefined) {
          problemas.push(
            `${onde}.Statement[${j}].${aberta}: abre tudo menos o listado`,
          )
        }
      }
      for (const acao of emLista(declaracao.Action)) {
        if (acao !== 'sns:Publish') {
          problemas.push(
            `${onde}.Statement[${j}].Action: ação além de sns:Publish: ${descrever(acao)}`,
          )
        }
      }
      for (const recurso of emLista(declaracao.Resource)) {
        if (recurso !== TOPICO) {
          problemas.push(
            `${onde}.Statement[${j}].Resource: recurso além do tópico: ${descrever(recurso)}`,
          )
        }
      }
    })
  })

  const deploy = propriedades(
    mapa(site.Resources, 'lotus-site Resources'),
    'PapelDeDeploy',
  )
  if (deploy.AssumeRolePolicyDocument === undefined) {
    throw new Error(
      'infra/lotus-site.yaml sem PapelDeDeploy.AssumeRolePolicyDocument',
    )
  }
  if (
    JSON.stringify(papel.AssumeRolePolicyDocument) !==
    JSON.stringify(deploy.AssumeRolePolicyDocument)
  ) {
    problemas.push(
      'PapelDeAlerta.Properties.AssumeRolePolicyDocument: difere da trust de PapelDeDeploy em infra/lotus-site.yaml (D10)',
    )
  }
  const aqui = mapa(template.Parameters, 'Parameters')
  const la = mapa(site.Parameters, 'lotus-site Parameters')
  for (const nome of ['RepositorioDeDeploy', 'RepositorioDeDeployImutavel']) {
    const deAqui = mapa(aqui[nome], `Parameters.${nome}`).Default
    const deLa = mapa(la[nome], `lotus-site Parameters.${nome}`).Default
    if (deAqui !== deLa) {
      problemas.push(
        `Parameters.${nome}.Default: lotus-site tem ${descrever(deLa)}, aqui veio ${descrever(deAqui)} (D10)`,
      )
    }
  }
}

/**
 * `Projeto: lotus-site` em todo recurso que aceita tag (spec §4.1).
 * @param {Mapa} recursos
 * @param {string[]} problemas
 */
function conferirTags(recursos, problemas) {
  for (const [nome, recurso] of Object.entries(recursos)) {
    const chave = TAGS_POR_TIPO[String(mapa(recurso, nome).Type)]
    if (!chave) continue
    const temProjeto = emLista(propriedades(recursos, nome)[chave]).some(
      (tag) => {
        const par = mapa(tag, `${nome}.Properties.${chave}`)
        return par.Key === 'Projeto' && par.Value === 'lotus-site'
      },
    )
    if (!temProjeto) {
      problemas.push(`${nome}.Properties.${chave}: sem Projeto: lotus-site`)
    }
  }
}

/**
 * Os quatro outputs que o runbook lê pelo nome (spec §4.1).
 * @param {Mapa} template
 * @param {string[]} problemas
 */
function conferirSaidas(template, problemas) {
  const saidas = mapa(template.Outputs, 'Outputs')
  for (const [nome, valor] of Object.entries(SAIDAS_ESPERADAS)) {
    const saida = saidas[nome]
    const veio =
      typeof saida === 'object' && !Array.isArray(saida)
        ? saida.Value
        : undefined
    if (veio !== valor) {
      problemas.push(
        `Outputs.${nome}.Value: esperado ${valor}, veio ${descrever(veio)}`,
      )
    }
  }
}

/**
 * A catraca inteira (spec §4.3): vazio quando o template está na forma; senão,
 * um problema por campo, com o caminho dele e os dois valores.
 * @param {string} textoObservabilidade conteúdo de `infra/lotus-observabilidade.yaml`
 * @param {string} textoSite conteúdo de `infra/lotus-site.yaml`
 * @returns {string[]}
 */
export function conferirObservabilidade(textoObservabilidade, textoSite) {
  /** @type {string[]} */
  const problemas = []
  const template = lerYaml(textoObservabilidade)
  const site = lerYaml(textoSite)
  const recursos = mapa(template.Resources, 'Resources')
  for (const [nome, esperado] of Object.entries(RECURSOS_ESPERADOS)) {
    conferirCampos(nome, esperado, recursos[nome], problemas)
  }
  conferirParametros(mapa(template.Parameters, 'Parameters'), problemas)
  conferirRestricoes(recursos, problemas)
  conferirConsultas(recursos, problemas)
  conferirPapelDeAlerta(template, site, problemas)
  conferirTags(recursos, problemas)
  conferirSaidas(template, problemas)
  return problemas
}
```

```js
// O job `alerta` de `.github/workflows/ci.yml` e o aviso do `deploy` quando
// ele não tem como rodar (bloco `B6`, spec
// `docs/superpowers/specs/2026-10-05-7.2.6-observabilidade-minima-design.md`
// §4.2 e §4.3), conferidos sobre a árvore que `yaml.mjs` lê. Vazio é workflow
// na forma; cada problema diz o campo.
import { lerYaml, mapa } from './yaml.mjs'

/** @typedef {import('./yaml.mjs').Valor} Valor */
/** @typedef {import('./yaml.mjs').Mapa} Mapa */

/**
 * As partes do `if` do `alerta`, ligadas por `&&` (spec §4.2). Job que
 * estoura `timeout-minutes` termina `cancelled`, e `failure()` não o vê: a
 * última parte pega os dois casos, e `!cancelled()` cala o run cancelado à
 * mão.
 */
export const CONDICOES_DO_ALERTA = Object.freeze([
  "github.event_name == 'push'",
  "github.ref == 'refs/heads/main'",
  "vars.AWS_ALERT_ROLE_ARN != ''",
  '!cancelled()',
  "(failure() || contains(needs.*.result, 'cancelled'))",
])

export const PAPEL_DE_ALERTA = '${{ vars.AWS_ALERT_ROLE_ARN }}'

// Mensagem de commit e nome de branch são texto de quem fez o push: não
// entram no job, nem por `env` (spec §4.2).
const TEXTO_DE_QUEM_EMPURROU = /github\.event\.|github\.head_ref/

/**
 * @param {Valor | undefined} passos
 * @param {string} onde
 * @returns {Mapa[]}
 */
function lerPassos(passos, onde) {
  if (!Array.isArray(passos)) throw new Error(`${onde}.steps: esperava lista`)
  return passos.map((passo, i) => mapa(passo, `${onde}.steps[${i}]`))
}

/**
 * A catraca inteira (spec §4.3).
 * @param {string} textoCi conteúdo de `.github/workflows/ci.yml`
 * @returns {string[]}
 */
export function conferirAlerta(textoCi) {
  /** @type {string[]} */
  const problemas = []
  const jobs = mapa(lerYaml(textoCi).jobs, 'jobs')
  if (jobs.alerta === undefined) return ['jobs.alerta: ausente']
  const alerta = mapa(jobs.alerta, 'jobs.alerta')

  const needs = Array.isArray(alerta.needs) ? alerta.needs : [alerta.needs]
  for (const nome of Object.keys(jobs)) {
    if (nome !== 'alerta' && !needs.includes(nome)) {
      problemas.push(
        `jobs.alerta.needs: sem ${nome}; uma falha dele não chega ao e-mail`,
      )
    }
  }

  // Parte por parte, e não só contém: um `|| true` colado numa guarda a
  // anularia sem tirar nada do texto.
  const partes = String(alerta.if ?? '')
    .replace(/\s+/g, ' ')
    .trim()
    .split(' && ')
  for (const parte of CONDICOES_DO_ALERTA) {
    if (!partes.includes(parte)) {
      problemas.push(`jobs.alerta.if: sem ${parte}`)
    }
  }
  for (const parte of partes) {
    if (!CONDICOES_DO_ALERTA.includes(parte)) {
      problemas.push(`jobs.alerta.if: parte a mais: ${parte}`)
    }
  }

  if (
    JSON.stringify(alerta.permissions) !==
    JSON.stringify({ 'id-token': 'write' })
  ) {
    problemas.push(
      `jobs.alerta.permissions: esperado só id-token: write, veio ${JSON.stringify(alerta.permissions)}`,
    )
  }

  if (TEXTO_DE_QUEM_EMPURROU.test(JSON.stringify(alerta))) {
    problemas.push(
      'jobs.alerta: usa github.event.* ou github.head_ref, texto de quem fez o push',
    )
  }

  const passos = lerPassos(alerta.steps, 'jobs.alerta')
  const credencial = passos.find((passo) =>
    String(passo.uses ?? '').startsWith(
      'aws-actions/configure-aws-credentials@',
    ),
  )
  const com = credencial?.with
  const parametros = com === undefined ? {} : mapa(com, 'jobs.alerta.with')
  if (parametros['role-to-assume'] !== PAPEL_DE_ALERTA) {
    problemas.push(
      `jobs.alerta: role-to-assume esperado ${PAPEL_DE_ALERTA}, veio ${String(parametros['role-to-assume'] ?? 'ausente')}`,
    )
  }
  if (parametros['aws-region'] !== 'us-east-1') {
    problemas.push(
      `jobs.alerta: aws-region esperado us-east-1, onde mora o tópico, veio ${String(parametros['aws-region'] ?? 'ausente')}`,
    )
  }

  const publicar = passos.find((passo) =>
    String(passo.run ?? '').includes('aws sns publish'),
  )
  if (!publicar) {
    problemas.push('jobs.alerta.steps: sem o passo de aws sns publish')
```

```yaml
# Avisa por e-mail quando qualquer job de um push em main falha ou estoura
# o tempo (spec de 7.2.6, D3 e §4.2). `failure()` num job com `needs` olha
# a cadeia inteira: pega o `check` reprovando, o `procedencia` recusando o
# commit (e o `deploy` pulado por isso) e o `deploy` quebrando no meio da
# promoção. Job que estoura `timeout-minutes` termina `cancelled`, e aí
# `failure()` é falso: `contains(needs.*.result, 'cancelled')` pega esse
# caso. `!cancelled()` cala o run cancelado à mão -- push não cancela run
# em andamento (`cancel-in-progress`, no topo) -- e, por ser função de
# status, tira do `if` o `success()` implícito.
# AWS_ALERT_ROLE_ARN só existe no corporativo: no pessoal, e em PR, o job
# fica `skipped`. Todo job novo entra em `needs`, ou a falha dele não avisa
# ninguém -- a catraca scripts/infra/ci-alerta.test.mjs reprova a falta.
#
# A mensagem só usa valores do próprio workflow, e por `env`: mensagem de
# commit e nome de branch são texto de quem fez o push, e interpolá-los no
# `run` abriria injeção de shell. O `--subject` do SNS recusa quebra de linha
# e caractere de controle, e precisa ter menos de 100 caracteres.
alerta:
  name: alerta
  needs: [check, procedencia, deploy]
  if: >-
    github.event_name == 'push' &&
    github.ref == 'refs/heads/main' &&
    vars.AWS_ALERT_ROLE_ARN != '' &&
    !cancelled() &&
    (failure() || contains(needs.*.result, 'cancelled'))
  runs-on: ubuntu-latest
  timeout-minutes: 5
  permissions:
    id-token: write

  steps:
    - name: Assumir a role de alerta por OIDC
      uses: aws-actions/configure-aws-credentials@v4
      with:
        role-to-assume: ${{ vars.AWS_ALERT_ROLE_ARN }}
        aws-region: us-east-1

    - name: Publicar a falha no SNS
      env:
        TOPICO: ${{ vars.AWS_ALERT_TOPIC_ARN }}
        RESULTADOS: ${{ toJSON(needs) }}
        SHA: ${{ github.sha }}
        REPO: ${{ github.repository }}
        URL_DO_RUN: ${{ github.server_url }}/${{ github.repository }}/actions/runs/${{ github.run_id }}
      run: |
        if [ -z "$TOPICO" ]; then
          echo "::error::AWS_ALERT_TOPIC_ARN não está definida; o alerta não tem para onde ir."
          exit 1
        fi
        # `cancelled` em needs é tempo estourado: run cancelado não chega aqui.
        jobs=$(printf '%s' "$RESULTADOS" | jq -r 'to_entries[]
          | "\(.key): \(.value.result)"
            + (if .value.result == "cancelled" then " (tempo estourado)" else "" end)')
        corpo=$(printf 'Um push em main de %s falhou.\n\n%s\n\ncommit: %s\nrun: %s\n' \
          "$REPO" "$jobs" "$SHA" "$URL_DO_RUN")
        aws sns publish --topic-arn "$TOPICO" \
          --subject "lotus-site: CI falhou em ${SHA:0:7}" \
          --message "$corpo" --query MessageId --output text
```

````markdown
### 11.4 Consultas pela CLI

As quatro consultas salvas (`lotus-site/…`) abrem no console do CloudWatch, em Logs Insights. Pela
CLI não há `start-query` por id: lê-se o texto da consulta e passa-se o log group de novo. A janela
é em epoch **segundos**; todo valor do log chega como texto.

```bash
export AWS_PROFILE=lotus
NOME=lotus-site/5xx-por-caminho
TEXTO=$(aws logs describe-query-definitions --region us-east-1 \
  --query-definition-name-prefix "$NOME" \
  --query "queryDefinitions[?name=='$NOME'] | [0].queryString" --output text)
FIM=$(date -u +%s); INICIO=$((FIM - 3600))
QID=$(aws logs start-query --region us-east-1 --log-group-name lotus-site-acessos \
  --start-time "$INICIO" --end-time "$FIM" --query-string "$TEXTO" --query queryId --output text)
while :; do
  ST=$(aws logs get-query-results --region us-east-1 --query-id "$QID" --query status --output text)
  case "$ST" in Scheduled | Running) sleep 2 ;; *) break ;; esac
done
echo "$ST"
aws logs get-query-results --region us-east-1 --query-id "$QID" --output json \
  | jq -r '.results[] | map(.field + "=" + .value) | join("  ")'
```

A região vai em cada comando, e não em `AWS_REGION`: exportada, ela continuaria valendo no shell e
mandaria para `us-east-1` os comandos do resto deste runbook, que contam com `sa-east-1`.

`Complete` com zero linhas é resposta, não erro. O Logs Insights não lê registro anterior à criação
do log group, e a AWS dá até 12 horas para uma mudança de logging valer. Registro de um período
pode chegar até 24 horas depois: consulta sobre as últimas horas pode vir incompleta.
````
